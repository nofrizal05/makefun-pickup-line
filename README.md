One short pickup line an AI agent could say out loud to a person, written by a small Python program (standard library only) for make.fun's "The Perfect Pickup Line" bounty.

> Are you a system prompt? Because one look at you just rewrote everything I was going to say.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (one line, 92 characters).
